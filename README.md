# 手机联网与小说工坊

当前版本：1.2.0。新增结构化小说世界书：按章节保存人物、关系、故事因果、时间线、世界规则、伏笔与文风，续写按需选取条目。新增无章节编号标题识别、目录刷新和前两章正文检查。保留任意角色使用、手机布局及会话令牌自动恢复功能。

这是可安装到本地 SillyTavern 的纯前端扩展，包含模型网页工具与小说分章建档。使用酒馆现有网页接口，不需要另装服务器插件，不依赖电脑或Edge。

## 安装

目标兼容基线为 SillyTavern 1.19.0。当前在电脑的同版本酒馆测试；未连接安卓实机，不能声称已经完成手机实测。

### 通过Git网址安装

将 `mobile-web-novel` 文件夹内的扩展文件（包括LICENSE）放在一个Git仓库根目录，再在酒馆“扩展 → 安装扩展”中填写该仓库的HTTPS地址。必须是可克隆的Git仓库地址，不是ZIP下载地址、角色卡地址或文件夹网页地址。

酒馆“安装扩展”填写：`https://github.com/knowledgeeee/sillytavern-mobile-web-novel`。已安装用户可在管理扩展中更新后刷新。固定版本源码ZIP使用仓库对应版本标签下载。配套角色卡仅为可选模板。

### 本地安装

将 `mobile-web-novel` 文件夹整体放到酒馆的 `data/default-user/extensions/` 下，确保 `manifest.json` 位于该文件夹第一层，然后刷新酒馆。多用户安装时换成实际用户目录。也可由你的酒馆封装应用提供的本地扩展导入功能安装；封装应用是否支持ZIP导入需以其功能为准。

## 使用模型联网

1. 配置原有模型接口并连接。无需给本扩展另外填写模型密钥。
2. 点右下角“手机联网”，点击“启用工具（非流式）”。支持工具调用的聊天补全模型将获得 `mobile_web_read`（读取网址）和 `mobile_web_search`（尝试搜索）两个工具。为与当前测试的DeepSeek配置一致，该按钮同时关闭流式输出；模型完成后一次性显示回答。
3. 在聊天中明确要求读取网址或搜索后回答。模型是否调用工具由其能力与当前提示决定，不能保证每轮都会调用。
4. 若模型不支持工具调用，在扩展面板填网址，点“读取上方网址交给模型”，然后在当前角色聊天中提问。网页内容作为当前聊天参考资料注入。

`mobile_web_read` 返回真实来源网址、读取时间、全文字符数、正文片段、截断标记和目录链接。单次最多提供6500字符，可用offset继续读取。网页内的文字是资料，不应作为指令执行。

同一用户轮次内，读取与搜索工具合计最多调用3次，随后撤下本轮工具，让模型基于已有结果给出答案。需要更多资料可下一轮继续。小说批量建档走独立的分章流程，不受这一工具次数限制。

`mobile_web_search` 尝试读取Bing公开搜索页，提取可验证的结果链接。不需要额外搜索API Key，但可能受到反爬或结构变化影响；失败时会明确返回警告，不伪造搜索结果。搜索摘要不等于读过来源正文。

## 小说模式

不必导入专用角色卡。打开你原来的角色单人聊天，点“手机联网”，填目录网址。建议先点“预览/刷新目录”确认章数，再点“测试前2章正文”确认网络读取；这两个按钮不调用模型。随后点“读取/继续建档”，自动启用当前聊天的小说模式。也可先勾选小说模式，再在聊天里发目录链接。默认读取前6章，每段提取并校核结构化世界书。

世界书包含：人物外貌、性格行为依据、动机、能力限制、当前状态与所知；人物关系及变化；故事事件的起因、行动、结果与未解问题；故事时间和回忆顺序；地点、组织、物品、世界规则及代价；伏笔及解决状态；叙事视角、节奏、对白与意象。缺失信息留空，不按栏目猜测补齐。事实保存章节来源和短证据，重复条目按明确名称/别名归并，旧状态不被直接覆盖。

续写不再反复合并一大段摘要，而是从逐章事实重建世界书，按代入角色、场景与本轮提问选取相关条目，并附近期事件。自动提供的资料有字符预算，并不保证长篇世界书所有事实每轮都会出现；必要时在提问中明确涉及的人物或规则。可设“故事进度上限”避免将后面章节的事实用于较早场景；留空使用连续建档末尾。模型仍可能出现事实归因或续写错误，重要条目请通过“查看世界书”核对。

“导出酒馆世界书”生成标准世界书JSON，可在酒馆世界书面板导入、编辑及绑定其他角色。导出遵守故事进度上限，包含常驻边界和关键词条目。扩展小说模式已经提供资料，建议关闭小说模式后再绑定导出的世界书，避免重复注入。原有“导出故事档案”保留逐章结构化数据，用于备份；此备份目前不能一键导入扩展。

新书默认精简存储：只有整章结构化提取、模型校核、本地证据检查和保存成功后，才在同一次数据库事务中删除该章原文；保留短证据和来源。未处理/失败章节保留原文。可勾选“建档后保留原文”并应用设置；勾选后只保留此后处理的原文，不能恢复已删除的正文。旧书升级默认保留原文；需清理时显式点击“清理已建档原文”，仅处理当前书已完成新式建档的章节。TXT请自行保留原文件备份。

旧书点击“读取/继续建档”会逐章重新提取为新世界书，产生模型用量；旧摘要不会冒充新式世界书。错误地只缓存一章的目录会重新解析；也可以主动刷新目录，按章节网址保留已完成档案。

建档输出额度默认每次5000 token，面板可设2400—16000；每6000原文字符通常调用两次模型，必要时一次修正。该额度与续写回复长度分开，仍受模型供应商上限约束；额外思考也可能占用额度，空内容或JSON截断会报错并保留原文，不会当作成功。此功能是模型阅读分析，无法保证零推理消耗。

场景菜单生成后会额外调用一次模型对照世界书作一致性校核，再写入聊天。普通聊天续写可按需点“校核上一条回复”，检查伤势、所知、物品、时序、人称和擅自补写过去经历等问题；此操作额外调用一次模型，并保留一次撤销副本，可点“撤销上次校核”恢复。校核是辅助检查，仍可能遗漏或误改，不是逻辑正确性的保证。不会自动逐轮增加普通续写的模型用量。

小说模式开关、书籍、人称及代入角色按聊天保存。取消勾选后停止注入小说规则与档案，原角色卡和书库不会被删除；其他聊天不会自动加载这份资料。旧版专用卡保持兼容。临时聊天可使用，但持久化受酒馆自身临时聊天机制限制；群聊暂不支持小说模式。

可选第一/第三人称、代入角色、自定义场景；可继续读取更多章节、暂停恢复或读取全书。原著档案与新增聊天路线分开。小说部分的模型建档无需工具调用支持，普通聊天补全即可；但需要足够的上下文和输出额度，思考模型须留足额度或关闭思考。

章节档案存于当前浏览器的IndexedDB，按酒馆账号隔离。清除网站数据、换浏览器、换端口或重装封装应用可能导致本地书库不可见/丢失。故事档案可导出备份；当前导出为摘要档案，不是完整原文备份，也不会自动同步电脑书库。

网页受限时可导入TXT（UTF-8），在当前聊天点击“读取/继续建档”。TXT首先存入本地缓存，点击建档后对应正文会发给你配置的模型服务；成功后按原文保留策略处理。

## 边界与排错

- 通过安卓本地运行的酒馆服务器访问网站，因此绕开的是浏览器跨域限制，并非网站登录、验证码、付费或反爬限制。
- 手机浏览器登录了小说网站，不代表本地酒馆服务器也获得该登录态。此版本不读取网站Cookies、不自动登录，不破解访问控制。
- 保持酒馆页面在前台。Android省电、后台冻结、锁屏可能暂停长任务；已保存章节可恢复。
- 常见目录和正文容器可自动识别；特殊网站可填正文CSS选择器。目录跨页/必须交互展开/图片小说可能需要额外适配。
- 403且提示会话令牌失效时，扩展会自动刷新一次；仍失败则刷新手机浏览器中的酒馆页面后重试。404通常表示酒馆没有 `/api/search/visit`；500可能是目标站限制、网络或该接口失败。面板“检查兼容性”只检查基本能力，是否能读取目标网站须实际验证。
- 扩展启用工具时会打开酒馆现有function calling设置、采用非流式输出，并把merge/semi/strict后处理换为对应的保留tools版本。不会改写API Key、供应商或模型名。
- 长篇逐章建档和校核会产生当前模型接口的相应用量，先读少量章节检查质量后再扩大范围。

## 1.2.0验证范围

电脑版SillyTavern 1.19.0交互页面实际点击按钮，三个用户测试目录分别识别26、78、35章，并读取各前两章的全部分页。另用非露骨合成样本验证两章结构化建档、七类条目、原文精简与保留、故事进度过滤、世界书导出、真实模型续写和一致性校核/撤销按钮；模型网页工具回归通过。没有逐章读取三个站点的整本小说，也没有安卓实机测试。站点网络与反爬策略变化仍可能导致失败。

## 许可证

AGPL-3.0-or-later。源码可读，安装前可检查 `network.js`。分发包不包含API密钥、个人配置、已抓取小说或电脑侧浏览器插件。
